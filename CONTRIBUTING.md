# Contributing

Contributions are accepted under the repository's `AGPL-3.0-only` license.
Contributors must have the right to submit their work and must identify any
third-party material in `docs/source-tracking.md` before adding it.

Evaluate existing implementations before designing substantial new behavior.
Reuse compatible licensed code when it reduces adaptation cost; record the
upstream revision, file hashes, license and local modifications in
`docs/source-tracking.md` and preserve required notices. Public availability
alone is not permission to copy branding, media or code. Add focused tests for
observable interoperability and record intentional differences from upstream.

Run `npm run check` before submitting a change. Security reports should follow
`SECURITY.md` rather than a public issue.
